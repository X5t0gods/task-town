- `npm run check`：JavaScript 语法、三个 HTML 页面 ID 和静态资源引用检查通过。

覆盖内容：

1. 家长发布、孩子查看、领取、提交、家长验收；孩子不能自行发奖励。
2. 退回重做后再次打卡；重复与并发验收只发一次星星。
3. 愿望兑换扣星、余额不足、请求重试不重复扣星、退回只退款一次。
4. 不同家庭和同一家庭不同孩子的数据隔离；角色、CSRF、跨站请求校验。
5. 每日任务按北京时间零点开放，单次任务不重复，过期后禁止新领取。
6. 必须拍照的任务校验、图片类型校验和照片私有访问。
7. 家长密码、孩子口令更改后旧会话失效；角色会话独立。
8. 服务重启后保留记录和登录；会话到期失效。
9. 服务器执行输入边界、限流、暂停任务和下架愿望规则。
10. 页面和资源正常访问，数据库、配置和源码不会作为静态文件暴露。
11. 大于 500 条历史时保留待验收记录；完整导出不截断历史。
12. MySQL SQL 备份恢复到另一个测试库后，余额、登录和照片保留；多连接验收不丢余额，并发不同兑换申请不会超支。

## 浏览器流程

在独立家长与孩子页面登录本地 MySQL 演示库，实际操作：

1. 家长在手机尺寸布局点击浮动发布按钮，发布“自己整理床铺”。
2. 孩子看到这个真实任务，领取后提交打卡，余额仍为 8。
3. 家长在手机底部导航进入任务验收，通过后余额变为 13。
4. 成长记录出现对应的 +5 星星流水和完成记录。
5. 验证手机发布弹窗的关闭、取消与背景滚动锁定。
