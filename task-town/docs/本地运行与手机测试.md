# 本地运行与手机测试

当前交付是手机优先的独立网页，后端连接本机 MySQL。阿里云上线和手表端按最新要求暂缓。

## 已配置好的本机环境

| 项目 | 当前配置 |
| --- | --- |
| Node.js | 22.14.0 |
| MySQL | 8.0.41，使用本机已安装的程序 |
| MySQL 地址 | `127.0.0.1:3307`，仅本机可连接 |
| 正式数据库 | `task_town` |
| 演示数据库 | `task_town_demo` |
| 数据目录 | `<项目专属 MySQL 数据目录>` |
| 网站端口 | `3000`，监听局域网，供手机访问 |
| 应用连接配置 | 项目根目录 `.env` |
| 独立实例管理配置 | `.local/mysql.json` |

没有修改原来的系统 MySQL 服务。Windows MySQL 在中文路径下启动数据字典失败，因此为本项目创建了单独的 ASCII 数据目录，并限制为当前 Windows 用户访问。数据没有存到云端。

不要删除 MySQL 数据目录、`.env` 和 `.local/mysql.json`，也不要将含密码的本地配置提交到代码仓库或发给他人。源码包不包含这些文件。

## 启动

正式使用：双击 `启动项目.cmd`。首次没有正式账号，在家长页创建家庭，再添加孩子。随后把家庭码、孩子账号、6 位数字口令交给孩子。

演示：双击 `启动演示.cmd`。演示账号如下：

- 家长账号：`demo_parent`
- 家长密码：`TownDemo2026!`
- 演示家庭码：`以启动输出为准`（重新生成演示库后可能变化，以启动输出为准）
- 孩子账号：`xiaobao`
- 孩子口令：`246810`

也可以在项目目录运行 `npm start`。第一次从纯源码安装，需要先执行 `npm ci` 和 `npm run setup:local`。MySQL 独立实例会随网站启动自动检查并启动；不需要注册 Windows 系统服务。

如果提示 `EADDRINUSE`，说明 3000 端口已有程序在用。项目已经启动时，直接打开网页即可；切换正式库与演示库前，应先停止上一份网站服务。

## 手机访问

1. 手机与电脑连接同一 Wi-Fi，电脑保持开启。
2. 在电脑启动窗口找到“手机与电脑连接同一 Wi-Fi 后访问”的地址。
3. 本次地址是 `http://<电脑局域网IP>:3000`，家长路径是 `/parent.html`，孩子路径是 `/kid.html`。
4. 两台设备分别使用家长账号和孩子账号登录。家长发布后，孩子页面在可见状态下约 5 秒内同步，也可以刷新。

手机上的 `localhost` 或 `127.0.0.1` 指向手机自己，不能用于访问电脑上的项目。IP 可能在切换网络或重启路由器后变化，每次以启动窗口显示的为准。

当前本地配置没有锁定 `APP_ORIGIN`，可以通过本机地址和局域网地址访问。如果自行设置此项，来源必须与访问地址完全一致。

## 已做的手机适配

- 家长与孩子各自的底部导航，常用页面适合拇指切换。
- 家长任务列表优先展示，点击浮动“发布任务”再打开表单。
- 发布表单用原生对话框承载，背景停止滚动，支持关闭和取消。
- 手机任务卡片单列显示；表单字号 16px，主要操作按钮放大。
- 底部导航、浮动按钮和提示条留出系统安全区域。
- 打卡支持手机文件选择或相机入口，照片在浏览器缩小后上传，服务器限制为 2MB。
- 360、390、430px 窗口检查没有发现页面横向溢出，桌面布局仍可使用。

你已确认手机能够正常打开家长登录页面，局域网访问验证通过。实际手机的相机权限、相册格式、软键盘及 Safari/Android 浏览器行为，需要在设备上继续确认。浏览器尺寸模拟不替代真机测试。

## 连接 MySQL 查看数据

使用 Navicat、Workbench 或其他本地客户端时，填写 `127.0.0.1`、`3307`、用户名 `task_town_app`，数据库选择 `task_town` 或 `task_town_demo`。密码在 `.env` 的 `DB_PASSWORD` 中，直接在本地复制，不需要发到聊天中。

应用启动时按 `database/schema.sql` 自动创建缺少的表，不会清空已有任务。任务奖励、兑换扣星和退还使用 InnoDB 事务、行锁与唯一约束；不能只靠前端修改余额。

## 备份和停止

```powershell
npm run backup
```

此命令备份当前 `.env` 指定的库，输出到 `backups/*.sql`，包括账号、任务、照片和流水。备份采用 MySQL 的事务一致性导出。完整恢复流程已在独立临时测试库验证；恢复真实业务库前，请保留当前数据，并确认目标库，避免误覆盖。

关闭启动窗口或按 Ctrl+C 停止网页。需要同时停止项目专属 MySQL 时执行：

```powershell
npm run db:stop
```

再次运行 `npm start` 会自动启动这个独立 MySQL 实例。

## 常见问题

| 现象 | 处理 |
| --- | --- |
| 手机打不开，电脑能打开 | 核对同一 Wi-Fi、当前电脑 IP、电脑是否休眠，检查专用网络的 Windows 防火墙提示与路由器 AP 隔离 |
| 登不进去 | 正式库和演示库账号独立；孩子需要家庭码、孩子账号及 6 位口令，家长密码不能用于孩子入口 |
| 403 跨站操作 | 检查是否手动填写了与当前地址不符的 `APP_ORIGIN` |
| MySQL 无法启动 | 查看专属实例目录下的 `mysql-error.log`，确认 3307 未被其他程序占用；不要修改原系统 MySQL 服务 |
| 上传照片失败 | 选择 JPG、PNG、WebP；原图超过 20MB 或无法读取时需另选照片，HEIC 需要先转换 |
| 新电脑启动不了 | 安装 Node.js 22 与 MySQL 8，运行 `npm ci`、`npm run setup:local`；本机实例密码和数据不随源码包传播 |

本地 HTTP 地址用于开发测试，后续部署云服务器时再配置域名和 HTTPS。
